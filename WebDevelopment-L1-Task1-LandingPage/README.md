# NEXORA — Modern Tech Startup Landing Page

## About the Project

NEXORA is a modern, responsive landing page designed for a fictional technology startup. It uses a clean layout, professional typography, and a dark theme with purple and cyan accents.

## Technologies Used

* HTML5
* CSS3
* Flexbox and CSS Grid
* Responsive Media Queries

## Features

* Sticky navigation bar
* Hero section with call-to-action
* Feature cards and About section
* Contact section and footer
* Responsive design for mobile and desktop
* Smooth scrolling

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
